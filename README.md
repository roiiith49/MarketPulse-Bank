# BankBoost-ML
Predictive models and exploratory data analysis for the Bank Marketing Dataset (Kaggle).  
> Convert more leads — analyze campaign factors and build ML models to predict deposit subscriptions.

## 🚀 Project summary
This project analyzes the Bank Marketing Dataset (Kaggle) to understand which factors influence customer subscription to a term deposit, perform EDA, feature engineering, and build classification models (Logistic Regression, Random Forest, XGBoost) to predict campaign success.

## 📥 Dataset
Source: `janiobachmann/bank-marketing-dataset` (Kaggle)  
Kaggle page: https://www.kaggle.com/datasets/janiobachmann/bank-marketing-dataset
